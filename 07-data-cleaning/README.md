# 🧹 07. Data Quality & Anomaly Audit

> **Challenging datasets before trusting them — missing values, duplicates, and anomaly detection.**

---

## 📌 Data Quality Checklist
1. **Completeness**: Are there missing records or null fields?
2. **Accuracy**: Do numerical values fall within realistic boundaries?
3. **Consistency**: Are category definitions standardized across time periods?
4. **Uniqueness**: Are primary key IDs free of duplication?
5. **Validity**: Do timestamps and dates follow proper chronological order?
