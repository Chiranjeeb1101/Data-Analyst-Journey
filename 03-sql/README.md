# ⚡ 03. Production SQL Mastery

> **The core technical skill of an elite analyst — solving complex business problems in SQL.**

---

## 📌 Core Competencies
- **Aggregation & Filtering**: GROUP BY, HAVING, conditional logic with CASE WHEN.
- **Advanced Joins**: INNER, LEFT, FULL OUTER, avoiding row duplication bugs.
- **Common Table Expressions (CTEs)**: Structuring clean, readable multi-step analytical pipelines.
- **Window Functions**: ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), LEAD(), SUM() OVER(), NTILE().
- **Analytical Queries**: Cohort analysis, retention matrices, running totals, moving averages, funnel drop-offs.
- **Optimization**: Execution plans, index concepts, analytical query design.
