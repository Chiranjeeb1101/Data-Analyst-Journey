# Lifelong Data Analyst Learning System & Cadence

> **The operational system for continuous, permanent skill growth, evidence generation, and career progression.**

---

## 🔄 The 5-Level Learning Cycle

```text
CONCEPT & THEORY
        ↓
HANDS-ON PRACTICE
        ↓
BUSINESS APPLICATION
        ↓
EVIDENCE PRODUCTION
        ↓
PORTFOLIO & PLAYBOOK INTEGRATION
```

---

## ⏰ Operational Cadence

### 1. Daily Cadence (1–2 Hours)
* **Goal**: Focus on deliberate technical & business practice.
* **Activities**:
  * Solve 1-2 complex SQL queries (window functions, cohort aggregations, CTEs).
  * Learn or practice an analytical pattern (e.g., RFM, Cohort, Pricing analysis).
  * Code in Python/Pandas or construct Power BI DAX measures.
  * Document key learnings in the respective module folder.

### 2. Weekly Cadence (Evidence Output)
* **Goal**: Convert weekly learning into tangible evidence.
* **Activities**:
  * Complete a mini-analysis or mini-case study.
  * Document an analytical pattern in `20-analytical-patterns/`.
  * Update `progress-log.md` with achievements and artifacts.

### 3. Monthly Cadence (Deep-Dive Case Study / Project)
* **Goal**: Tackle an ambiguous end-to-end business problem.
* **Activities**:
  * Complete a comprehensive case study in `18-case-studies/` or project in `19-projects/`.
  * Cover all stages: *Problem Framing → Data Quality → SQL/Pandas Analysis → Power BI Dashboard → Executive Memo*.
  * Conduct peer/self code review against `templates/analytical-report-template.md`.

### 4. Quarterly Cadence (Skills Audit & Direction Check)
* **Goal**: Review analytical growth and identify capability gaps.
* **Activities**:
  * Complete self-assessment in `skills-matrix.md`.
  * Identify weak areas (e.g., Statistics, DAX, Storytelling) and update focus for the next 90 days.
  * Refine personal Data Analyst Playbook in `20-analytical-patterns/`.

### 5. Yearly Cadence (Strategic Review)
* **Goal**: Evaluate overall professional growth and portfolio impact.
* **Activities**:
  * Evaluate career progression against `career-roadmap.md`.
  * Audit repository projects for code quality, business impact, and documentation clarity.
  * Plan next year's analytical focus areas and strategic domain deep-dives.
