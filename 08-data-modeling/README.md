# 🏗️ 08. Data Modeling & Dimensional Architecture

> **Designing Star Schemas, defining table grain, and building fact/dimension tables.**

---

## 📌 Core Concepts
- **Table Grain**: What does one row represent?
- **Star Schema Architecture**: Central Fact Tables surrounded by Dimension Tables.
- **Fact Tables**: Transactional, Periodic Snapshot, Accumulating Snapshot.
- **Dimension Tables**: Customer, Product, Geography, Time/Date Dimensions.
