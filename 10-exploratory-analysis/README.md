# 🔍 10. Exploratory Data Analysis (EDA)

> **Systematic exploration to uncover patterns, anomalies, and underlying data structures.**

---

## 📌 EDA Dimensions
- **Univariate Analysis**: Single variable distributions, histograms, box plots.
- **Bivariate Analysis**: Cross-tabulations, scatter plots, correlation matrices.
- **Multivariate Analysis**: Segmented breakdowns, driver isolation.
