# Comprehensive Data Analyst Skills Matrix & Competency Rubric

> **Self-evaluation rubric across all 21 capability layers. Rate skills from 1 (Novice) to 5 (Elite Master).**

---

## 📊 Capability Rating Scale

* **Level 1 (Novice)**: Theoretical understanding; requires step-by-step guidance.
* **Level 2 (Foundational)**: Can execute standard tasks independently; needs support on complex edge cases.
* **Level 3 (Competent)**: Solves real-world business problems independently; clean execution & solid logic.
* **Level 4 (Advanced)**: Deep mastery; optimizes query efficiency, handles complex ambiguity, mentors others.
* **Level 5 (Elite Master)**: Strategic thought leader; designs enterprise data models, metric systems, and influences C-suite decisions.

---

## 🎯 Competency Matrix Across Capability Stack

### 1. Business & Problem Framing
| Capability Layer | Self-Rating (1-5) | Benchmark Requirement for Level 4+ |
| :--- | :--- | :--- |
| **Business Understanding** | [ ] | Decodes revenue drivers, unit economics, and operational bottlenecks across SaaS, E-Commerce, Logistics. |
| **Problem Framing** | [ ] | Deconstructs vague executive statements into measurable, hypothesis-driven analytical sub-questions. |
| **Analytical Thinking** | [ ] | Consistently isolates variables, avoids spurious correlations, and identifies root causes vs symptoms. |
| **KPI & Metric Design** | [ ] | Builds metric trees, dictionary definitions, and balances leading vs lagging indicators. |

### 2. Technical Execution
| Capability Layer | Self-Rating (1-5) | Benchmark Requirement for Level 4+ |
| :--- | :--- | :--- |
| **SQL Mastery** | [ ] | Writes complex CTEs, window functions (`LAG`/`LEAD`, running totals), query optimizations, execution plan analysis. |
| **Excel Mastery** | [ ] | Uses XLOOKUP, INDEX/MATCH, dynamic arrays (`FILTER`, `UNIQUE`), SUMIFS, and Power Query for advanced modeling. |
| **Python & Pandas** | [ ] | Builds reproducible data pipelines (`pd.read_csv`, `.groupby()`, `.pivot_table()`, `.merge()`, string/date cleaning). |
| **Data Cleaning** | [ ] | Audits missingness, duplicates, outliers, data type drift, and anomaly detection systematically. |
| **Data Modeling** | [ ] | Constructs Star Schema models, defines exact grain for facts/dimensions, and enforces relational integrity. |

### 3. Statistics & Advanced Analytics
| Capability Layer | Self-Rating (1-5) | Benchmark Requirement for Level 4+ |
| :--- | :--- | :--- |
| **Statistics** | [ ] | Applies descriptive/inferential stats, distributions, confidence intervals, regression, and effect sizes accurately. |
| **Exploratory Analysis** | [ ] | Conducts systematic univariate, bivariate, and multivariate analysis to uncover non-obvious patterns. |
| **Advanced Analytics** | [ ] | Performs Cohort Analysis, Funnel Conversion, RFM Segmentation, Retention Analysis, and Driver Decomposition. |
| **Experimentation** | [ ] | Calculates required sample size, evaluates A/B test results, guards against p-hacking, and recommends business actions. |
| **Forecasting** | [ ] | Applies time-series decomposition, moving averages, trend extraction, and seasonal adjustments with error bounds. |

### 4. BI & Communication
| Capability Layer | Self-Rating (1-5) | Benchmark Requirement for Level 4+ |
| :--- | :--- | :--- |
| **Visualization Principles** | [ ] | Selects precise chart types based on cognitive load, hierarchy, annotations, and accessibility principles. |
| **Power BI & DAX** | [ ] | Builds star schemas, custom DAX measures, time-intelligence calculations, and executive dashboard UX. |
| **Data Storytelling** | [ ] | Translates quantitative findings into executive summaries answering *What, Why, So What, Now What*. |
| **Stakeholder Communication** | [ ] | Defends analytical assumptions, presents trade-offs, communicates uncertainty, and drives decision adoption. |

## 📝 Verification Checklist

- [ ] Can solve an unfamiliar business question in SQL within 30 minutes.
- [ ] Can explain the difference between correlation and causation to a non-technical manager.
- [ ] Can identify table grain instantly by examining raw rows.
- [ ] Can build an executive dashboard that clearly indicates what action to take.
